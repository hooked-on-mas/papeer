# Bundled Japanese fonts

Downloaded from Adobe's official Source Han release branches on 2026-09-10.
Unmodified Japanese subset OpenType fonts; the original SIL Open Font License
and copyright notices are included alongside each family.

The serif regular face is used for body text. The sans bold face is used for
titles, section headings, and the heading part of run-in subsections. Fonts are
loaded from application assets, without requiring system-wide installation.
