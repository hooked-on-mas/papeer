# Original app artwork

On 2026-10-18, the repository owner confirmed that the existing app icons are
their own work and may be publicly distributed. The original artwork is retained
in `papeer.png`, `papeer.ico`, `frontend/public/papeer.png`, and the platform and
tray icons in `frontend/src-tauri/icons/`. No replacement artwork is needed.

Bundled fonts have their own licenses and provenance in `fonts/README.md`.
`google-oauth.json` contains public OAuth client configuration, not user tokens.
