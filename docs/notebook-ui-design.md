## 2. 方針：何を共通にし、何を分けるか

**共通（そのまま使う）**
- 用紙の描画（`PdfPane` の pdf.js 描画、`preservePaperColor`）
- 書き込みのしくみ（`InkOverlay` / `useInkEditor` / `inkStore`、自動保存・Undo・下書き・安定ページID）
- 付箋（位置付箋・付箋タブ）、右パネル（メモ・資料）、紐づけ、左パネルのツリー本体
- ページ移動・倍率の内部処理（`navigation.ts` の `movePage` / `jumpToPage` / `changeZoom`）、ホイール・ピンチ・キー処理

**分ける（ノート専用に作る）**
- 画面の器：`Reader`（PDF）と `NotebookView`（ノート）を別コンポーネントに
- ツールバー：ノートは「書く道具＋ページ＋倍率」を1段にまとめた専用ツールバー
- ページ一覧：横の帯をやめ、用紙の左に縦のページサイドバー
- 右クリック：用紙・サムネイル・左パネルの行それぞれにノート用メニュー
- 文言：ノートの画面には「PDF」「原文」「訳文」「本文」「論文」を出さない

内部のタブID `"reader"` やストアの `activeTab` はそのまま（保存済みの画面状態・ショートカットを壊さない）。変えるのは表示と中身だけ。

## 3. ノートを開いたときの画面

```
┌───────────────────────────────────────────────────────────────────────┐
│ 📓 研究アイデア帳        ✎        ［↗ 関連論文 2］［情報・整理］［⋯］ │ ← ヘッダー
│ ノート · 機械学習 · 12ページ · 10/17 更新                              │
├───────────────────────────────────────────────────────────────────────┤
│ ［ノート］［メモ］［付箋］                                              │ ← タブ
├───────────────────────────────────────────────────────────────────────┤
│ ▤ │ ✋ ✏ 🖍 ◻ T ⌫ 📌 │ ●●●●● 太さ▾ │ ↶ ↷ │ ‹ 3/12 › │ ページ全体▾ │ ⛶ │ ⋯ │ ← ノートのツールバー（常に1段）
├───────────────────────────────────────────────────────────────────────┤
│  1 [▭]              ┌────────────────────┐                            │
│  2 [▭]              │                    │                            │
│  3 [■]              │                    │                            │
│  4 [▭]              │       用紙         │                            │
│  …                  │  （ページ全体）    │                            │
│  [＋]               │                    │                            │
│                     └────────────────────┘     ［次のページ ›］       │
└───────────────────────────────────────────────────────────────────────┘
  ↑ページサイドバー：用紙の左の余白に置く（用紙は縮まない）。余白が足りないときは細いつまみに畳む（§3.4）
                                                    ↑右下の余白（最後のページは［＋ 新しいページ］）
```

### 3.1 ヘッダー
- タイトル：ノート名。クリック（または F2）でその場で名前を変更できる（`renamePaperFile` を使う。拡張子なし）。
- 2行目：`ノート · <フォルダー名> · nページ · <更新日>`。専用ノートは `<持ち主名>の専用ノート`（持ち主名はクリックで持ち主を開く）。
- 「論文情報・整理」→ 種類で文言を変え、ノートでは「情報・整理」。
- 「↗ 関連論文 n」ボタン（独立ノートのみ）：押すとポップオーバーで一覧・追加・外す・開く。今の折りたたみ帯（`RelatedItems compact`）は廃止して、縦の帯を1段減らす。
- 「その他」（ノート用）：名前を変更…／持ち主を変更・独立させる…／専用ノートを作る…（独立ノートのみ）／書き込み付きPDFとして保存…／保存フォルダーを開く／—／ライブラリから削除。訳語・サマリー・PDF書出しなどは出さない（今も caps で隠れている。ノート用メニューとして明示的に組む）。

### 3.2 タブ（決定：ノートは「ノート」、PDFも「PDFを読む」をやめる）
- 中央のタブ名を種類で変える：PDF は「**本文**」、ノートは「**ノート**」。Ctrl+1 は同じ。
  - PDF側を「本文」にする理由：ほかのタブ（サマリー・チャット・メモ・付箋・論文マップ）はどれも名詞で、「PDFを読む」だけが動詞句。中身は原文と日本語訳の両方なので「原文」「PDF」より「本文」が合う。並びは「本文｜サマリー｜チャット｜メモ｜付箋｜論文マップ」。
  - 「PDFを読む」はほかに、文献の詳細と調査完了の通知のボタン（`ResearchDetails.tsx`・`researchJobs.ts`）でも使っている。こちらは「論文を開く」に揃える（タブ名ではなく動作のボタンなので動詞のまま）。
  - 変更の及ぶ所：`AppShell.tsx` のタブ、上の2か所のボタン、`README.md` のショートカット表、`docs/annotations.md`・`docs/web-research.md`、e2e（`memos.test.ts`・`notesOrganization.test.ts`・`references.browser.test.ts`）のタブ名・ボタン名、コード中のコメント（`ReaderArea.tsx`・`sidePanel.ts`）。
- ほかのタブ（メモ・付箋、資料ありならチャット）は今のまま `tabAvailable` で決まる。

### 3.3 ノートのツールバー（1段）
左から：
1. **▤ ページサイドバーの開閉**
2. **書く道具**：選択（✋。描かずにスクロール・書き込みの選択。今の「範囲選択」をここに統合）／ペン／蛍光ペン／図形（線・矢印・四角・円は2段目で選ぶ）／文字／消しゴム／付箋
3. **↶ ↷**（Undo / Redo）
4. **ページ**：`‹ 3/12 ›`。番号部分をクリックすると入力欄になり Enter で移動（Ctrl+G も同じ）。PDF用の「移動」ボタン・「戻る」は出さない
5. **倍率**：ノート用（§4.5）
6. **⛶ 集中表示**
7. **⋯**：書き込み付きPDFとして保存／範囲キャプチャ／用紙を変更…（このページ）／右パネル（メモ・資料）／消しゴムの設定

出さないもの：目次、論文内検索（段Gの手書きOCRで検索が入るまで）、原文|訳文の切替、本文選択、「書き込み」の開閉ボタン、書き込みのあるページ一覧。

**ツールバーは常に1段**にし、道具を持ち替えても用紙の位置・大きさが変わらないようにする（今は道具によって2段目が出たり消えたりして、そのたびに用紙が上下に動き、縮む）。
- 色と太さは、幅があれば同じ段の道具の右に並べる（よく使う5色＋太さ）。
- 幅が足りないとき、または消しゴムの設定や選択中の操作（コピー・切り取り・削除）は、選んでいる道具のボタンをもう一度押すと出る小さなポップオーバーに入れる。範囲を選んだ直後のコピー等は、選択範囲のすぐ横に浮かぶ小さなバーにも出す（PDFの文字選択バー `SelectionToolbar` と同じ考え方）。
- 部品は今の `InkToolbar` の2段目を切り出して使う。

幅が足りないときは、今の `fitReaderToolbar` と同じ考え方で 6→5→3 の順に「⋯」へ畳む。書く道具とページは最後まで残す。

### 3.4 ページサイドバー（今の横帯の置き換え）

**いちばんの要件：開いておいても、書ける範囲を狭めない。**

考え方：ノートは「ページ全体」倍率で開く（§4.5）。このとき用紙の大きさは**画面の高さ**で決まり、横長の画面では用紙の左右に余白が残る。たとえば表示域が 1200×800px なら、A4縦の用紙は幅およそ 540px で、左右に 300px 以上ずつ空く。サイドバーはこの**余白に置く**。用紙と並べて場所を取り合う列にはしないので、開いても用紙は1pxも縮まない。

| 状態 | 見え方 |
|---|---|
| 左の余白がサイドバーの幅（約110px）＋すき間より広い | サイドバーをその余白にずっと表示する。用紙は動かない |
| 余白が足りない（窓が狭い、横長の用紙、倍率を上げた、右パネルを開いた） | サイドバーを左端の細い**つまみ**（幅約20px、今のページ位置を示す目盛り）に自動で畳む。つまみをクリック、またはマウスを乗せると用紙の上に重ねて開き、ページを選ぶ・用紙に書き始める・外をクリックするのいずれかで畳む |
| ▤ で「隠す」にした | つまみも出さない（ツールバーの ‹ 3/12 › だけ） |

- ▤ ボタンは「自動（既定）／隠す」の切り替え。状態はこのPCに保存（ui-state）。
- 書いている最中（ペン先が触れている間）に、重ねたサイドバーが自動で開くことはない。マウスを乗せて開くのは、マウスでつまみに触れたときだけ。ペン・タッチはクリック（タップ）で開く。
- 重ねて開いたときは用紙の端に半透明の影をつけ、用紙の上だと分かるようにする。

中身：
- 用紙の左に縦に並ぶサムネイル（書き込み入り、今と同じ描画）。現在ページは枠で強調。見えている付近だけ描画（今の仮想化を縦向きに）。
- クリックで移動。余白に出ているときは開いたまま、重ねて開いたときは移動後に畳む。
- 並べ替え：ドラッグ、またはフォーカスして Alt+↑↓（今の Alt+←→ を縦向きに）。
- サムネイルの右クリック（§4.2 のページメニュー）。
- 一番下に「＋ ページを追加」（末尾に追加）。
- 今の上部帯にあったボタン（後ろに挿入・末尾に追加・複製・削除・用紙を変更）は右クリックメニューと「＋」に移し、常設のボタン列は置かない。

縦の場所も守る：上部はヘッダー・タブ・ノートのツールバー（1段）の3段だけにし、今の「ページ一覧」帯・「関連論文」帯・書き込みツール帯（最大2段）はなくす。今より最大3〜4段（約120〜160px）、用紙を縦に大きく使える。

### 3.5 用紙の右下
- 「次のページ ›」の小さなボタンを用紙の**右下の余白**に置く。最後のページでは「＋ 新しいページ」（同じ用紙設定で末尾に追加し、そのページへ移動）。
- 用紙の下に帯を置くと「ページ全体」のとき用紙がその分縮むため、帯にはしない。右の余白がなければ用紙の右下角に重ねる半透明の小さなボタンにし、ペン先が近づいたら消す（書くのを邪魔しない）。
- 用紙の上の「ノート」キャプションは出さない（PDFの「原文／日本語訳」区別のためのもの）。

## 4. 操作の詳細

### 4.1 ページ移動（一本化）
| 手段 | 動き |
|---|---|
| ツールバー `‹ n/m ›` | 前後・番号入力 |
| ページサイドバー | クリックで移動 |
| 用紙の右下のボタン | 次のページ・新しいページ |
| キー | ← → / PageUp PageDown でページ、Home End で先頭・末尾（今の `readerKeyAction` を使う） |
| ホイール（決定：めくれるようにする） | ページ端でさらに回すとめくる（PDFと同じ。「ページ全体」なら用紙全体が見えているので、ひと回しでめくれる）。**ペン先が触れている間だけ無効**にする。今は書き込み道具を選んでいる間ずっと無効で、ノートは常にペンを選ぶためホイールでめくれない。最後のページでホイールを回しても新しいページは作らない（誤操作でページが増えないように） |

### 4.2 右クリックメニュー（ノート用）
**用紙の上**（`PdfContextMenu` の代わりに `NotebookPaperMenu`）
- 貼り付け（書き込みのクリップボードがあるとき）
- ここに付箋を貼る
- —
- このページの後ろにページを追加／このページの前にページを追加
- このページを複製
- 用紙を変更…
- —
- このページを削除（最後の1ページは無効）

右クリックはマウスの右ボタンのみで開く。タッチの長押しでは開かない（手のひらが触れて誤って出るのを避ける。作業中の変更の考え方を引き継ぐ）。ペンのボタン（button 5 は消しゴム扱い）も今のまま。

**ページサイドバーのサムネイル**：上と同じページ操作（「ここに付箋を貼る」「貼り付け」は除く）＋「このページへ移動」。

前に挿入は今の API にない（`insert` は「後ろ」）。前のページの後ろに挿入する（先頭の前は `insert` の `page_id` 省略を先頭扱いにする小さなサーバー変更が要る。§6 段2で対応）。

### 4.3 新規作成
**入口**
| 場所 | 項目 | 作成先 |
|---|---|---|
| 左パネル上部 | 「ノートを作る」（今のまま。「PDFを追加」と並べる） | 追加先フォルダー |
| フォルダー行の右クリック | 「ここにノートを作る…」（新規） | そのフォルダー |
| ツリーの空白部分の右クリック | 「ノートを作る…」「フォルダーを作成…」「PDFを追加…」（空白のメニュー自体が新規） | 追加先フォルダー |
| 論文行・独立ノート行の右クリック | 「専用ノートを作る…」（今のまま） | その持ち物 |
| キー（決定） | Ctrl+Alt+N（新規。Ctrl+Shift+N はフォルダー作成で使用中）。ショートカット一覧（`hotkeys.ts`）と README にも載せる | 追加先フォルダー |
| 閉じた左パネルのアイコン列 | 今のまま | 追加先フォルダー |

**作成ダイアログ**
- 「作成先：機械学習 ▾」を表示し、その場で変えられる（専用ノートは「持ち主：〇〇」の表示のみ）。
- 既定名は「ノート 10/17」（同じ名前が同じ場所にあれば「ノート 10/17 (2)」）。開いた時点で名前を全選択し、そのまま打てば置き換わる。
- 用紙は**前回選んだもの**を既定にする（このPCに保存）。用紙の見本は今のまま。
- Enter で作成。

**作成後**：中央で開いてペンを選ぶ（今のまま）＋左パネルで新しい行を表示・選択（`reveal-paper`）。

`newNotebook(owner?)` を `newNotebook({ owner?, collection? })` に変える。

### 4.4 左パネルのノート行
- 2行目：`12ページ · 10/17 更新`。読書状態は出さない（`itemCapabilities` に `readStatus` を足し、ノートは false）。タグは今のまま。
- 右クリック（ノート用 `NotebookMenu`。PaperMenu から種類で分ける）：
  - 名前を変更…（F2）
  - 関連論文を追加…（独立ノートのみ）
  - 専用ノートを作る…（独立ノートのみ）
  - 持ち主を変更・独立させる…
  - フォルダーを移動 ▸（今の「分類を変更」。ノートでは「フォルダー」と呼ぶ）
  - タグ ▸
  - 情報・整理
  - —
  - 書き込み付きPDFとして保存…
  - 保存フォルダーを開く
  - —
  - ライブラリから削除
- 複数選択メニュー（`SelectionMenu`）はノートが混ざっても今のまま。ただし読書状態はノートには付けない（ノートだけの選択では項目を出さない）。

### 4.5 倍率
- ノート用の倍率を別に持つ（`notebookZoom`、ui-state に保存）。既定は「ページ全体」。
- ノートを開いている間は Ctrl+ホイール・Ctrl+=/−・倍率メニューがノート用を変える。PDFの倍率は変わらない。
- 倍率メニューの説明文から「原文・日本語訳」を外す。

### 4.6 集中表示
- ヘッダー・タブ・左パネルを隠す（今と同じ）。ノートのツールバーとページサイドバー（開いていれば）は残す。

### 4.7 文言の置き換え（ノートの画面）
| いま | ノートでは |
|---|---|
| PDFを読む（タブ） | ノート（PDFでは「本文」） |

## 6. 段階分け

各段で「型検査・lint・単体テスト・ノートのe2e」を通し、独立レビュー（高・中のみ差し戻し）を挟む。

**段1 画面の器を分ける**（見た目の大枠）
- `NotebookView` / `NotebookToolbar` / 共通 hook・部品の切り出し、`ReaderArea` の分岐、`Reader` からノート分岐を外す
- タブ名（PDF「本文」・ノート「ノート」）と「論文を開く」ボタン、ヘッダー（2行目・情報・整理・関連論文ボタン・ノート用その他）、文言の置き換え、ツールバーを常に1段に
- 横のページ帯はこの段では `NotebookView` の中にそのまま移す（段2で置き換え）
- 完了条件：ノートの画面に目次・原文訳文・本文選択・「書き込み」開閉・関連論文の帯が出ず、道具を持ち替えても用紙が動かない。PDFの画面はタブ名以外、見た目も動きも変わらない（タブ名を直した既存 e2e が通る）

**段2 ページまわり**
- ページサイドバー、用紙の右クリック、サムネイルの右クリック、用紙下のナビ／新しいページ、ホイールでめくる条件、ノート用倍率、先頭への挿入（サーバー）
- 完了条件：ページの追加・複製・削除・並べ替え・用紙変更がサイドバーと右クリックからでき、ページ移動の常設表示がツールバーの1か所＋サイドバーになる。e2e で「サイドバーを出しても用紙の大きさが変わらない」「窓を狭めるとつまみに畳まれる」を確かめる

**段3 左パネルと作成**
- フォルダー右クリック・空白右クリック・Ctrl+Alt+N、作成ダイアログ（作成先・既定名・前回の用紙）、作成後の表示、`NotebookMenu`、ノート行の2行目、`readStatus`
- 完了条件：フォルダーを右クリックしてそのフォルダーにノートが作れ、作った行が選ばれる

**段4 仕上げ**
- 集中表示・狭い幅での重ね表示・キーボードとスクリーンリーダーの確認、`docs/notebooks.md` 更新、引継ぎ書更新
- 実装メモ（段4）：集中表示はコード変更なしで要件を満たしていた（ツールバー・サイドバー・右下ボタンはもともと `NotebookView` の中で、余白判定は表示域の幅から出している）ため、e2e で確かめるだけにした。狭い幅は、必須だった「▤」と元に戻す／やり直すを任意に変え、窓が狭いときは「⋯」の項目に移す（設計にない追加。左パネルを開いたままの 640px では、必須の部品だけで行の幅を超えて切れたため）。畳む順は 色・太さ → 集中表示 → 倍率 → ▤ → 元に戻す／やり直す（`fitNotebookToolbar`。前の項目が畳まれたあとに小さな項目だけが残らないようにしてある）。

段F（AIで資料）・段G（手書きOCR）とは独立。どちらを先にしても衝突は少ないが、段Gでノートに検索が入るので、段1〜2を先に終えておくと検索の置き場所（ノートのツールバー）が決まっていて楽。

## 7. 今回やらないこと（理由つき）

| 項目 | 理由 |
|---|---|
| ページを縦に続けて表示（連続スクロール） | `PdfPane` は1ページずつ描く作りで、書き込み・付箋・保存の単位もページ。大改修になるため、まず用紙下の「次のページ／新しいページ」で書き続けやすさを補う。使ってみて足りなければ別段で検討 |
| ノートを丸ごと複製 | 新しいサーバー処理（ページ・書き込み・付箋・復旧記録のコピー）が要る。要望が出たら追加 |
| 長押しで右クリックメニュー | 手のひらが触れて誤って開くため。マウス右クリックと「⋯」で足りる |
| 用紙テンプレートの自作 | 今の用紙の種類で足りるか使って様子を見る |
| ノート内検索 | 手書きの文字が読めるようになる段G（OCR）で入れる |
