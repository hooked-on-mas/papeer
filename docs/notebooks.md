# 手書きノート

論文を読むのとは別に、白紙や罫線の用紙に手書きで書くための「ノート」です。ペン・蛍光ペン・図形・テキスト・消しゴム・付箋は PDF への書き込みと同じ道具で、自動保存・元に戻す／やり直す・書き込み付き PDF への書き出しも共通です。ノートは論文とは別の項目で、タブは「ノート」、メモ・付箋のタブは論文と同じように使えます。

- サイズ：A4、B5（182×257mm）、A5、Letter、16:9（180×320mm）。それぞれ縦・横。
- 罫線：無地、横罫7・6・5mm、方眼5・10mm、ドット5mm、コーネル。
- 色：白、クリーム、ダーク。画面のダーク表示でも用紙を反転しません。
- ページは1冊500枚まで。ページごとに別の用紙にもできます（縦横の混在も可）。

## ノートを作る

作る場所は次のとおりです。どれも「ノートを作る」ダイアログが開きます。

| 入口 | 作られる場所 |
| --- | --- |
| 左パネル上部の「ノートを作る」、閉じた左パネルのアイコン、`Ctrl+Alt+N` | 追加先のフォルダー |
| フォルダーを右クリック →「ここにノートを作る…」 | そのフォルダー |
| 左パネルの空いている所を右クリック →「ノートを作る…」（「フォルダーを作成…」「PDFを追加…」も並びます） | 追加先のフォルダー |
| 論文・独立ノートの行を右クリック、またはヘッダーの「その他」→「専用ノートを作る…」 | その論文・ノートの持ち物（専用ノート） |

ダイアログでは次を決めます。

- ノート名：最初は「ノート 10/17」（同じ場所に同名があれば「ノート 10/17 (2)」）。開いた時点で名前が選ばれているので、そのまま打てば置き換わります。
- 作成先：その場で変えられます。専用ノートは「持ち主」を表示するだけで、持ち主のフォルダーに置かれます。
- 用紙：サイズ・向き・罫線・色。見本を見ながら選べ、最初は前回作ったノートの用紙です（この PC に保存）。
- `Enter` で作成します。作るとすぐノートが開き、ペンが選ばれ、左パネルでは新しい行が選ばれて見える位置に出ます。

## ノートの画面

上から、ヘッダー、タブ（「ノート」「メモ」「付箋」）、ノートのツールバー（1段）、用紙の順に並びます。PDF のツールバーにある目次・論文内検索・原文と訳文の切り替えは出ません。

**ヘッダー**：ノート名をクリック（または `F2`）するとその場で名前を変えられます。2行目に「ノート · フォルダー名 · nページ」（専用ノートは「〇〇の専用ノート」）を表示します。「↗ 関連論文 n」（独立ノートのみ）で紐づけた論文を開く・追加する・外す、「情報・整理」でタグなどの整理、「その他」で名前の変更・持ち主の変更・独立・専用ノートの作成・書き込み付き PDF としての保存・保存フォルダーを開く・ライブラリからの削除ができます。

**ツールバー**：道具を持ち替えても用紙が上下に動かないよう、常に1段です。左から次のとおりです。

1. 「▤」：ページ一覧（次の節）を自動で出す／隠す。
2. 書く道具：選択、ペン、蛍光ペン、図形（直線・矢印・四角・丸）、テキスト、消しゴム、付箋。選んでいる道具をもう一度押すと、色・太さや消しゴムの設定など、その道具の設定が小さなウィンドウで開きます。「選択」は、書き込みを囲んで選び、コピー・切り取り・削除・色の変更などをする道具です（選んだ直後は、範囲のすぐ下にも同じ操作が出ます）。
3. 色と太さ：幅があれば道具の右に並びます。
4. 元に戻す・やり直す（`Ctrl+Z` / `Ctrl+Y`）。
5. ページ：`‹ 3 / 12 ›`。番号を入力して `Enter` で移動します（`Ctrl+G` でも入力欄へ）。
6. 倍率：「ページ全体」（用紙全体が収まる大きさ）、「幅に合わせる」、125〜400% など。
7. 集中表示、「⋯」。

「⋯」には、書き込み付き PDF として保存（ノート全体）、範囲キャプチャ、用紙を変更…（いま表示しているページ）、右パネル（メモ・資料）の開閉、消しゴムの設定が入っています。窓が狭くて入りきらないときは、色・太さ → 集中表示 → 倍率 → 「▤」 → 元に戻す／やり直す の順に、同じ操作が「⋯」の中へ移ります（書く道具とページ番号は最後まで残ります）。

## ページ一覧（サイドバー）

用紙の左に、ページのサムネイルが縦に並びます。サムネイルには書いた内容も表示され、いまのページは枠で示されます。一番下の「ページを追加」で末尾に1枚足して、そのページへ移ります。

- 開いていても用紙を狭めません。ノートは「ページ全体」の倍率で開くので、横長の画面では用紙の左右に余白ができます。サイドバーはその余白に置かれ、用紙の大きさも位置も変わりません。
- 余白がないとき（用紙が横長、倍率を上げた、右パネルを開いた、窓が狭い、など）は、左端の細いつまみに畳まれます。つまみにマウスを乗せるか、クリック（ペン・タッチはタップ）すると、用紙の上に重ねて開きます。ページを選ぶ、用紙に書き始める、ほかの場所を押す、`Esc`、`Tab` で外へ出る、のどれかで畳まれます。書いている最中（ペン先が触れている間）に、重なったサイドバーが勝手に開くことはありません。
- 「▤」で「隠す」にすると、つまみも出ません（ツールバーのページ番号だけで移動します）。この設定はこの PC に保存されます。

並べ替えは、サムネイルのドラッグ、またはサムネイルを選んで `Alt+↑` / `Alt+↓` です。`Enter`（または `Space`）でそのページへ移動します。ページを足す・複製・削除・用紙変更・並べ替えの前には、表示していないページや再起動前から残る下書きも含めて書き込みを保存します。保存できなかったときはページを変更せず、下書きを残します。

## 右クリック

右クリックはマウスの右ボタンだけで開きます。ペンやタッチの長押しでは開きません（手のひらが触れて誤って開くのを避けるため）。

- 用紙の上：貼り付け（書き込みをコピーしてあるとき）、ここに付箋を貼る、このページの前／後ろにページを追加、このページを複製、用紙を変更…、このページを削除（最後の1ページは削除できません）。書き込みを選んでその上で右クリックしたときは、書き込み用のメニュー（削除など）になります。
- サムネイルの上：「このページへ移動」と、用紙の上と同じページの操作（貼り付け・付箋を除く）。
- 左パネルのノートの行：名前を変更…（`F2`）、関連論文を追加…、専用ノートを作る…、持ち主を変更・独立させる…、フォルダーを移動、タグ、情報・整理、書き込み付き PDF として保存…、保存フォルダーを開く、ライブラリから削除。行には「12ページ」のようにページ数を出します（読書状態は出しません）。

## ページを移る・右下のボタン・ホイール

ページの移動は、ツールバーの `‹ ›` と番号入力、サイドバー、用紙の右下のボタン、キー（`←` `→` / `PageUp` `PageDown` / `Home` `End`）、ホイールでできます。

- 右下のボタン：「次のページ ›」。最後のページでは「＋ 新しいページ」になり、同じ用紙のページを末尾に足してそこへ移ります。用紙の右に余白があるときは余白に、ないときは用紙の右下の角に半透明で重なり、ペン先が近づくと消えます（書くのを邪魔しないため）。
- ホイール：ページの端でさらに回すと次・前のページへ移ります（用紙全体が見えているときは、ひと回しで移ります）。ペン先（マウスのボタンを押している間も）が触れている間は動きません。最後のページで回しても新しいページは作りません。

## 倍率

ノートの倍率は PDF とは別に覚えられ（この PC に保存）、初期値は「ページ全体」です。`Ctrl` + ホイール、`Ctrl` + `+` / `-`、`Ctrl+0`（「ページ全体」に戻す）、ツールバーの倍率で変えられ、PDF の倍率は変わりません。

## 集中表示

`F11`（Mac は `⌃⌘F`）か、ツールバーの集中表示ボタンで、ヘッダー・タブ・左パネルを隠して用紙を大きく使います。ノートのツールバー、ページ一覧、右下のボタンはそのまま使えます。やめるには同じボタンか `F11` です。集中表示の出入りで用紙の大きさが変わると、サイドバーは余白に収まるか、余白がなければつまみに畳まれ直します（用紙に重なったままになりません）。集中表示のときは、「⋯」に「情報・整理」も入ります。

## 狭い窓で使う

窓を狭くしていくと、ツールバーは上の順に「⋯」へ畳まれます。左パネルを開いたままの 640px 程度の窓でも、書く道具・ページ番号・「⋯」は切れずに使えます。サイドバーはつまみに畳まれ、右下のボタンは用紙の角に重なります。左パネルを閉じる（`Ctrl+B`）と、元に戻す／やり直すなどがツールバーに戻ります。

## キーボードと読み上げ

- ノートの道具は Tab で順に選べます。選んでいる道具のボタンは「押されている」と読み上げられ、設定が開くことはボタンの説明文で伝えます。
- ページ番号の欄は「ページ番号」、そのあとに「全12ページ」と総ページ数が読まれます。
- ページ一覧のつまみは、`Enter` で開いて、いまのページのサムネイルへフォーカスが移ります。`Esc` で畳んだとき、およびキーボードでページを選んだときは、フォーカスがつまみへ戻ります（マウス・ペン・タッチで選んだときは戻りません）。`Tab` で一覧の外へ出たときは、そのまま次の部品へ進みます。
- ページを足す・並べ替えるなどの変更中は「書き込みを保存してページを変更中…」が読み上げられます。

## 論文との紐づけ

独立した PDF 論文と独立ノートは、置き場所や持ち物を変えずに多対多で紐づけられます。紐づけは向きがなく、論文はフォルダーに残り、持ち物の構成も変わりません。専用ノートや、ほかの項目の持ち物になっているノートは対象外です。

- 作る：左パネルで論文（複数選択可）を独立ノートへドラッグします。ノートが混ざった選択は紐づけできません。右クリックの「ノートに紐づける…」（ノート側は「関連論文を追加…」）からも選べます。フォルダーへのドラッグは従来どおり移動です。
- 左パネル：紐づけのある論文・ノートの行に「↗n」を表示します。開くと持ち物の次に、紐づけ先を ↗ 付きの行で表示します。子の行は5件までで、残りは「ほか n件」から全件を選べます。↗ の行は展開できず、クリックで本体を開きます。右クリックの「フォルダー内で表示」で本体のフォルダーへ移り、「紐づけを外す」で紐づけだけを消します（論文もノートも残ります）。
- 画面：ノートのヘッダーの「↗ 関連論文 n」を押すと、紐づけた論文の一覧が開き、追加・解除・論文を開く操作ができます。論文の詳細にも「関連ノート」を表示します。
- 設定：「設定 → 表示」の「左パネルの紐づけ行を隠す」で、左パネルの ↗ の行と件数を隠せます（この PC だけの設定）。画面の関連論文・関連ノートは引き続き使えます。

紐づけの作成はサーバーでも検査し、独立した PDF 論文と独立ノートの組み合わせ以外は拒否します。どちらかの項目を削除すると、その紐づけも消えます。SQLite スキーマは version 8のままです。

## 書き込みと複製

複製は用紙・書き込み・付箋をコピーし、付箋には新しい識別子を割り当てます。用紙のサイズ・向きを変えても書き込みと付箋の位置はページ内の同じ比率を保ち、線や文字も用紙に合わせて伸縮します。付箋などの入力ダイアログは、保存またはキャンセルしてからページを操作します。サーバへ届いた要求は安定したページIDで扱うため、番号が変わっても別のページへ保存されません。

書き込み付き PDF は、ツールバーの「⋯」か、ヘッダーの「その他」、左パネルの右クリックから保存します。選んだ用紙と書き込みを描画した通常の PDF で、編集可能な書き込みデータはアプリ側に残ります。ノート本文の OCR・検索・チャット参照は別の段階で追加します。

## 持ち物（専用ノート）

独立ノートはフォルダー内で論文の先頭に表示します。専用ノートは持ち主の開閉ボタンで表示し、クリックすると中央で開きます。持ち物は最初の5件と「ほか n件」で全件を選べます。専用ノートにはさらにメモや専用ノートを入れられません。「その他」→「持ち主を変更・独立させる…」で持ち主を変えるか、現在の追加先フォルダーへ独立させます。中身や紐づけのある独立ノートを持ち物にする場合は、先にその中身を整理します。

持ち主を削除するとメモ・資料も削除されます。専用ノートの名前とページ数を確認し、「専用ノートを残して削除」か「持ち物もすべて削除」を選べます。残したノートは持ち主がいたフォルダーへ独立します。

## 保存形式と復旧（開発）

`papers/<id>/notebook.json`（version 1）が正本です。ページは変わらないIDとサイズ・向き・罫線・色を持ち、`original.pdf`はその表示用です。SQLiteスキーマはversion 8を維持し、既存の`papers.pages`、`pages`、`pdf_ink`、`bookmarks`を同時に更新します。既存の正規化座標をそのまま使うため、用紙変更時の座標変換は不要です。

ページ変更中は変更前後のPDFとJSONを復旧記録に保ち、`papers.sha256`のノート用世代記録でDBのコミットを判別します。コミット前の失敗は巻き戻し、コミット後に中断した場合はライブライブラリを次に開いたとき完了させます。同期比較・バックアップ検査は読取専用のSQLを使い、コピー上で復旧を実行しません。ページ操作・書込・付箋作成・切抜きは同じノートの操作ロックで順序を保ちます。専用ノートのフォルダー名は空文字に固定します。

ノートの書込は`/api/notebooks/{id}/pages/{page_id}/ink`、ページ変更は`/api/notebooks/{id}/pages`を使います。数値ページだけを送る旧PDF書込経路はノートでは拒否します。付箋作成・切抜きには`page_id`を併記し、サーバが現在の番号を解決します。画面の下書きとUndoは安定ID単位で保持し、削除が確認されたページだけ破棄します。

主な検証は`tests/test_notebooks.py`、フロントの保存競合テストと`e2e/tests/notebooks.test.ts`です。用紙描画、並べ替えと付箋/筆跡、削除済みIDの拒否、置換途中とDBコミット前後の故障、読取専用コピーの非変更、用紙変更後のPDF書出しを確認します。
