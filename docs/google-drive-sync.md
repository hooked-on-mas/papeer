# Google Driveのローカルフォルダーで同期

PC版Google Driveが同期するフォルダーをPapeerに指定します。Google Cloudでの登録、OAuthクライアントJSON、Papeer内でのGoogleログインは不要です。

## 最初のPC

1. PC版Google Driveで普段のGoogleアカウントにログインします。
2. Papeerの「設定 → 保存先・同期」を開きます。
3. 「フォルダーを選択」でGoogle Driveのマイドライブなど、PC間で同期されるフォルダーを選びます。選んだ場所の中の `Papeer-sync` が保存先になります。専用フォルダーの絶対パスを直接入力することもできます。
4. 「保存先を設定して同期」を押します。現在のPDF・書き込み・サマリーなどをまとめて保存します。
5. Papeerの処理完了後、**PC版Google Drive側の同期完了も確認**します。

## 別のPC

1. PC版Google Driveに同じアカウントでログインし、同期データが届くまで待ちます。
2. Papeerで、同じ `Papeer-sync` フォルダーのこのPC上のパスを指定します。ドライブ文字やユーザー名はPCごとに異なっていて構いません。
3. 「保存先を設定して同期」を押します。初回は使うデータの選択画面が出るので、元のPCのデータを選びます。
4. 読み込みが終わると画面が再読み込みされます。

Google Driveのミラーリングとストリーミングの違いは[Google公式ヘルプ](https://support.google.com/drive/answer/13401938?hl=ja)を参照してください。ストリーミングを使う場合は同期フォルダーをオフラインでも利用できる設定にすると扱いやすくなります。

## 保存対象と動作

PDF、書き込み、付箋、サマリー、翻訳結果・キャッシュ・修正履歴、メモ、チャット、タグ、フォルダー、辞書、テンプレート、設定、カスタムプロンプト、保存済みの読書位置を含むライブラリ全体を保存します。未送信のチャット入力など一時的な入力は対象外です。設定のうちCLIのパスとAPI URLはPCごとに保存し、同期しません。別のPCから届いたデータに書かれていても使いません。

作業用データは引き続きPC内に保持し、選んだフォルダーには完了した世代ごとに `.papeer-sync` ファイルを保存します。稼働中のSQLiteデータベースをGoogle Driveから直接開く方式ではありません。フォルダーへの保存とPC間の転送を分け、転送はPC版Google Driveに任せます。PapeerからGoogle Driveのクラウド転送完了は判定できません。

- 自動同期が有効なら起動後、1分ごと、終了前にフォルダーを更新します。AI処理中や設定画面を開いている間の定期同期は待機します。
- 「今すぐ同期」でも保存・読み込みできます。別PCに移る前にはGoogle Drive側の同期完了も確認してください。
- 両方のPCに変更があれば、自動上書きせず使うライブラリ全体を選択します。項目ごとの自動結合はありません。
- 取り込み前のデータは作業フォルダーと同じ階層の `*-before-restore-*` に残し、画面に退避先を表示します。
- 保存先が見つからない場合も作業用データはPC内に残ります。エラーや競合の後は定期同期を止めるので、保存先とGoogle Driveを確認して「今すぐ同期」で再試行してください。
- 「ローカル保存に戻す」はフォルダー同期を停止します。PC内と同期フォルダーのデータは削除しません。
- 保存先のパスや最終同期の基準、CLIのパスとAPI URLは、端末別に `%LOCALAPPDATA%\PapeerSync` に保存します。

## 容量と履歴

変更があるときはライブラリ全体を圧縮して保存します。ファイル単位の差分保存ではありません。変更がないときは新しい世代を作りません。読書位置だけの変更は新しい世代を作るきっかけにはせず、次に内容を同期するときに含めます。

履歴を自動削除しないため、ライブラリサイズと保存回数に応じて容量を使います。現行版には履歴の整理画面がありません。大きいライブラリでは自動同期を無効にし、必要なタイミングで手動同期できます。履歴は競合検出にも使うため、同期フォルダー内のファイルを部分的に削除しないでください。

Google Driveでファイルが順不同に届き、必要な履歴が不足している場合は取り込みを止めます。Driveの転送完了後に再試行してください。自動テストでは2つのローカルフォルダー間の転送、競合、破損、転送途中、保存先の消失を検証しています。実際のGoogle Drive経由の転送は各PCの設定に依存します。
