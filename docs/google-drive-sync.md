# フォルダー同期の廃止

PC版Google Driveのローカルフォルダーを指定するPC間同期は廃止しました。以前の同期フォルダーのデータは削除しません。この版はそのフォルダーへの保存・取り込みを行いません。

- このPCの作業データの保存先を変える場合は、「設定 → 保存先・同期」の「このPCの保存先」を使います。[保存先の変更手順](storage-location.md)を参照してください。
- Google Driveへの保存とWeb閲覧は、同じ画面の「Google Drive API・Web閲覧」を使います。[接続手順](google-drive-web.md)を参照してください。以前のフォルダー同期とは保存形式が異なり、APIへの接続と初回アップロードが必要です。

以前の同期でこのPCに残した履歴は、「設定 → バックアップ」から引き続き復元できます。保存先を変えても履歴を引き継ぎます。
