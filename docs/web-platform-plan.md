# Papeer: Windows / iPad Web版の仕様

更新日: 2026-10-18。Web版はPCで翻訳したPDFの閲覧とPDFへの追記に対応する。翻訳・AI操作はPC版に限定する。

## 実装した構成

- PCアプリはローカルsidecarで翻訳・PDF生成・ライブラリ管理を行う。
- PCからGoogle Drive APIへライブラリを直接保存する。Drive for desktopや同期フォルダーは不要。
- GitHub PagesがReactのWebアプリを配信し、ブラウザーはGoogleへログインしてDrive APIを直接読み書きする。
- Webでは原文・日本語訳・手書きノートを読み、ペン・蛍光ペン・文字メモを追加する。追加サーバーや起動中のPCは不要。
- Webでの追記はDriveへ保存され、PCの次回アップロード（手動または起動中5分ごとの自動処理）で取り込まれる。

```text
PCで翻訳・編集 → Drive APIへスナップショット保存 → PagesのWeb版で閲覧
PCへ追記を取り込み ← Driveの追記ファイル ← Webで手書き・文字メモ
```

## 環境による操作の違い

| 機能 | Windowsアプリ | Web版 |
| --- | --- | --- |
| 原文・訳文PDF、保存済みノート | 閲覧・編集 | 閲覧・追記 |
| PDFへのペン・蛍光ペン・文字 | 編集 | 追加・Web追記の消去・元に戻す・やり直す |
| 既存のPC書き込み | 編集 | 表示。Webの消しゴムでは消さない |
| メモ資料・付箋・チャット履歴 | 作成・編集・閲覧 | 保存済みの内容を閲覧 |
| 翻訳・再翻訳・AIへの質問 | 利用可能 | 操作・API呼び出しなし |
| Codex・AIキー・モデル・端末設定 | 表示 | 画面・設定読込を起動しない |
| 削除・フォルダー整理・復元 | 利用可能 | 提供しない |
| Drive認証 | デスクトップOAuth、DPAPI | Web OAuth、トークンはメモリーのみ |

`frontend/src/app/AppShell.tsx` と `frontend/src/web/main.tsx` をそれぞれのhost入口にする。同じPC上のChromeもWebとして動く。画面枠、階層ライブラリの行、幅変更可能な左パネル、ヘッダー、タブ、ページ操作、PDF描画設定、対訳分割、本文横のサマリー/チャット/メモdock、手書き描画・座標を共用する。WebはDrive用閲覧adapterを使い、PCの終了・job監視や設定画面は起動しない。具体的な責務と契約は[Astraによる設計](runtime-architecture.md)を参照。

## 書き込みの保存と競合

原文と訳文それぞれのPDFのSHA-256・項目ID・ページを追記に記録する。PDF本体は書き換えず、追加・削除をUUID付きの不変JSONファイルとして保存する。PCのスナップショットをWebから上書きしない。複数タブ・端末での追記はIDで統合し、削除は端末の時計やアップロード順に依存しない。

ブラウザーは通信前に1操作ずつlocalStorageへ下書きを保存する。失敗時には未保存件数と再試行を表示する。再読み込み後も下書きを回復し、Driveへの保存成功後に端末の下書きを除く。ブラウザーのサイトデータを削除すると未送信の下書きは失われる。

PCは排他的な同期処理中に追記を検証し、SQLiteの手書きと取り込み履歴を同じトランザクションで保存する。再試行で同じ線を増やさない。PCで取り込み後の線を消しても、古い追加操作から復活させない。Webでは取り込み済みの操作を再描画しないので二重にならない。

翻訳PDFを作り直すなどしてSHA-256が変わった場合、古い追記はDriveに保持し、別のPDFへ適用しない。Webに案内を表示する。旧PDFへの書き込みを新しいPDFへ移す機能は提供しない。

「PDF本体を保存」は元のPDFを保存する。Web追記は別データであり、このダウンロードには含めない。PCへの取り込み後はPCの既存の書き込み付きPDF出力を使える。

## iPadと検証

Pointer EventsでApple Pencil・マウスを扱い、通常は指の操作をスクロールに使う。「指でも書く」を有効にすると指で描ける。閲覧モードはテキスト選択を妨げない。狭い画面ではライブラリとツールバーを折り返す。

ブラウザーテストは実際のPythonライブラリから日本語訳PDFとPC手書きを出力し、Webの描画・保存・通信失敗・再読み込み・複数タブ・PCへの再取り込みまで確認する。Googleの通信はテスト用に置き換える。タブレット幅とペンのPointer EventsはChromiumで検証する。実GoogleアカウントでのOAuth・Driveの往復と、iPad実機Safari・Apple Pencilは別途実機確認が必要。

## 今後の範囲

Web翻訳・AI APIキー入力・ChatGPTログイン・Web上のチャット生成は提供しない方針で確定する。左右分割表示・倍率操作・主要な画面部品の共通化は対応済み。PC付箋や既存メモのWeb編集・ページ構成変更は今回の範囲に含めない。
