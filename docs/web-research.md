# Web検索と参考文献の取り込み

## チャットで調べる

入力欄の「Web検索 ON/OFF」で、次の質問でWebを検索するかを選びます。既定はOFFです。論文ごとの選択を保存し、アプリを開き直しても引き継ぎます。本文の参照範囲（この論文・選んだ論文・フォルダー内）とは独立しています。

- OFF：指定した論文の本文と、明示的に添付した調査結果で回答します。
- ON：本文に加えてWebを検索し、本文のページ引用とWebの出典リンクを分けて表示します。

検索状態と出典は質問・回答に保存します。現在のスイッチをOFFにしても、過去の回答の「Web検索あり」や出典は変わりません。検索で見つかった関連文献は、回答中の文献カードを開くと概要・入手先・PDFを確認できます。

Web検索はCodex CLI・Claude Code CLI・Antigravity CLIに対応しています。設定のAI接続を切り替えても、同じスイッチ・参考文献の詳細画面・PDF取り込みを使えます。API／ローカルモデルの接続はWeb検索に未対応で、検索スイッチは使えません。通常の翻訳・サマリー作成はWeb検索を有効にしません。Web検索の出典を確認できないときは、その質問を成功した回答として履歴に保存しません。

Claude Codeでは検索時だけ `WebSearch`・`WebFetch` を有効にします。組織のポリシーなどで検索が利用できない場合は、出典なしの回答を調査結果として保存しません。Antigravityでは実行ごとに一時フォルダーへ専用エージェントを作り、検索時は `search_web`・`read_url_content`、検索しないときは回答の終了処理だけを使用可能にします。検索時の自動承認はこの構成内に限定され、コマンド実行・ファイル操作・MCP・別エージェントの呼び出しは公開しません。ユーザーの設定ファイルは変更しません。

実装の根拠：[Claude Codeのツール](https://code.claude.com/docs/en/tools-reference)、[Antigravityのエージェント構成](https://www.antigravity.google/docs/subagents/)、[AntigravityのWebツール](https://www.antigravity.google/docs/sdk/tools/)。CLIが古い場合は更新してください。

## 参考文献の内容と入手先

「参考文献」タブの一覧から文献を選ぶと詳細へ移動します。「一覧に戻る」で検索条件とスクロール位置を引き継ぎます。「内容・入手先をWebで調べる」で、指定した文献の概要、確認した出典、直接取得できる公開PDFを調べます。

### AIで情報収集

「AIで情報収集」は既定でOFFです。ONにすると、表示中の論文の参考文献について概要・出典・公開PDFの入手先を、追加の確認なしで最大5件を同時に取得します。1件終わるたびに次の文献を補充します。選んだ文献を次の収集で優先し、同じ文献が一覧に重複している場合や取得済みの場合は再取得しません。AIの利用枠を使用します。

ON/OFFはこの端末に保存します。参考文献パネルを表示している間に未取得の文献を最大5件並行で処理し、別の画面では実行中の取得が終わったところで待機します。OFFにすると新しい取得を止め、実行中の自動取得すべてに中止を要求します。手動で開始した処理は止めません。接続が途切れた場合は待機し、取得に失敗した場合は一時停止して「収集を再開」を表示します。PDFの追加と本文サマリーの作成は、それぞれのボタンで実行します。

### 関連する論文とグラフ

[Connected Papersの共引用・共通参考文献による探索](https://www.connectedpapers.com/about)を参考に、「関連する論文」と「文献の類似性」グラフを追加しています。共通の参考文献や、一緒に引用された論文の数を候補ごとに表示します。関係の強さは共有件数を双方の引用集合の大きさで正規化して計算します。グラフでは関係が強い文献を近くに置き、年代を色、ライブラリ内の被引用論文数を円の大きさで表します。線に矢印がある「引用関係」と、共有する引用情報を線で結ぶ「文献の類似性」を切り替えられます。

一覧は引用順（関連する論文では関係が強い順）、新しい順、ライブラリ内の被引用順で並べ替えできます。ここでの関連性と被引用数は保存済みPDFから確認できた情報に限られ、分野全体の引用数やConnected Papersのデータベースを表すものではありません。

概要には「抄録に基づく」「公開本文に基づく」「書誌情報のみ」の区別と確認日を表示します。文献を特定できなかったときはその状態を表示し、PDF候補を出しません。参考文献のDOI・arXiv IDと検索結果が食い違う場合も保存せず、原文の確認と再検索を案内します。再検索しても、既に関連付けたPDFとその版は保持します。

## PDFを取り込む

公開PDFが複数ある場合は、公開元と版（出版版・著者最終稿・プレプリント・未確認）を選びます。保存先は元の論文のフォルダーを既定とし、別のフォルダーも選べます。「取り込み後にサマリーを作成」は任意で、既定はOFFです。

この画面では、Webで見つかった公開PDFを取り込みます。直接取得できる公開PDFがない場合は「出典・入手先」から公開元を確認できます。既に関連付けた論文や同じ内容のPDFは再利用し、既存のサマリーは上書きしません。

PDFは100MBまでです。取得時は転送先も確認し、公開インターネット上のファイルに限ります。ログイン画面などのHTML、空のPDF、パスワード付きPDFは取り込めません。

取り込みが終わっても、表示中の元の論文は切り替えません。文献の詳細に「PDFを読む」「サマリーを見る」を表示します。取り込んだPDFには元の参考文献との関連付けを保存し、引用ネットワークに登録済み文献として反映します。

## サマリーと比較

サマリーは取り込んだPDFの本文から作成し、日本語訳の作成は不要です。Webで読んだ抄録の概要とは別に扱います。本文を読み取れないスキャンPDFはOCRを案内し、PDFを保存した状態で残します。

サマリー作成でエラーや中止が起きても、取り込んだPDFと元の文献との関連付けは保持します。「サマリーを作成」で再試行できます。

「元の論文と比較する」は、元の論文と取り込んだ論文をチャットの参照対象に選び、調査結果と質問の下書きを添付します。送信とWeb検索の選択はユーザーが行います。PDF・サマリーを開いた後は「元の論文の参考文献へ戻る」で、選択・探索範囲・絞り込み・一覧の位置を引き継いで戻れます。

## 保存

調査結果と取り込んだ論文の関連付けはライブラリ内のデータベースに保存し、チャットには送信時の出典と調査結果を保存します。既存のバックアップ・復元・フォルダー同期で引き継ぎます。古いライブラリは自動移行し、既存の本文とチャット履歴は保持します。

本文の検索・参考文献の抽出・引用ネットワークは保存済みPDFを対象とします。Web検索を行っても、インターネット全体の被引用ネットワークは自動取得しません。
