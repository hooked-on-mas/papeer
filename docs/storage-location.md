# このPCの保存先

「設定 → 保存先・同期」の「このPCの保存先」で、PDF・ノート・メモ・書き込み・設定など、ライブラリ本体を保存するフォルダーを選べます。Google Driveへの保存は、同じ画面の「Google Drive API・Web閲覧」で設定します。

## 変更手順

1. 「フォルダーを選択」で保存したい場所を選びます。その場所の中の `Papeer` を使います。空のフォルダー、またはまだ存在しないフォルダーの絶対パスを直接入力することもできます。
2. 「保存先を変更」を押します。変更先が表示され、この時点では元の保存先を使い続けます。「変更を取り消す」で取り消せます。
3. Papeerを終了し、もう一度起動します。終了までに保存した最新の内容を新しい保存先にコピーし、データベースとファイルを確認してから切り替えます。初回の起動はコピーに時間がかかることがあります。

元の保存先のデータは残ります。既にファイルが入ったフォルダーには上書きしません。空き容量不足・コピー失敗・変更先の使用中などで切り替えられないときは、元の保存先を使い、設定画面に理由を表示します。変更先を選び直すか、予約を取り消してください。

Google Driveの接続情報、Drive上の保存ライブラリとの対応、このPCの履歴、最近開いた論文の記録は引き継ぎます。端末専用の設定・履歴・認証情報は、従来どおりこのPC専用の場所に残します。

保存先と変更予約は、`PapeerSync/storage-location.json`（LinuxはXDG stateの`papeer/storage-location.json`）に保存します。`PAPEER_DATA_DIR` または `PAPERDESK_DATA_DIR` を指定して起動した場合は、環境変数を優先し、画面からの保存先変更はできません。

変更後のフォルダーが見つからない場合は、空のライブラリを作らず停止します。移動したフォルダーを元に戻すか、外付けドライブを接続してください。
