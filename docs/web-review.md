# Web版の復旧・保存レビュー（2026-10-18）

対象はDrive APIを使う閲覧・PDF追記・共通画面・PWA。Webからの翻訳やサーバーは追加しない。

## 画像レビュー（2026-10-19）

幅320・375・390・430pxと横844pxを、CSSピクセルのスクリーンショットでも確認する。日本語訳、2段組の原文、150%拡大、読書メニュー、狭い画面のメニュー、ライブラリ、入力中の文字メモ、書き込み設定、保存メモ、ダーク表示を撮影する。高DPI画像を大きく表示しただけでは、スマホ上の本文の小ささを見落とすため、`scale: "css"`でも確認する。

| 画像で見つけた点 | 対応 |
| --- | --- |
| メニューの「保存ライブラリ」が1文字ずつ改行される | 見出しと選択欄を上下に並べ、見出しが1行になることも検証する。 |
| メニュー内の接続操作が人型アイコンだけ | 「Google接続」の文字を表示する。 |
| 色入力のHEX文字列が欠け、選んだ色が分かりづらい | ネイティブ入力を44pxの色見本に重ね、色と操作領域を確保する。 |
| 2段組の本文は幅合わせでも小さく、拡大がメニュー内にある | 幅375px以上のバーへ150%拡大・幅合わせボタンを追加する。狭い画面では従来の倍率メニューを使う。 |

メニューの文字も標準14px相当にする。ダーク表示でアイコンが黒く見えた画像はテーマ遷移の途中だったため、描画完了を待って撮り直す。アイコンの前景とバー背景のコントラストも検証する。ダーク表示の不具合を修正した扱いにはしない。

試験用PDFによるレビューであり、利用者の全PDFの読みやすさを保証するものではない。2段組の幅合わせは依然として本文が小さく、拡大やピンチが必要な場合がある。PDFを自動で組み直す機能は追加しない。iPhone実機のネイティブ色選択画面・キーボードは別途確認が必要。

## 修正した問題

| 対象 | 問題と修正 |
| --- | --- |
| Google接続 | 待機が終わらない状態をキャンセル・180秒の期限で解消。キャンセル後の遅い認証結果を無視する。SDK取得失敗時に再試行でき、接続復帰後にも読み込む。 |
| Drive通信 | 本文の読み取りまで120秒の期限を適用。ログアウト・アカウント変更時に通信を中断し、古い結果を採用しない。 |
| 再ログイン | 新しい権限でライブラリ・PDFを再取得し、古いログインの本文を残さない。キャンセル時は既存の閲覧を維持する。切替中は編集を一時停止する。 |
| 文字メモ | 配置前の入力も端末へ保存。ライブラリ・文書の版・ページで分離し、ページ移動・更新後も戻せる。他タブの変更を検出した場合は上書きしない。 |
| 保存容量不足 | 保存できなかった線を画面に残して再保存・破棄を選べる。端末に保存できない編集がある間は画面内の移動を止め、終了時の警告を要求する。保存済みという誤表示を避ける。 |
| 同期再試行 | 初期化・更新を多重実行せず、回復後の古いエラーを解消。保存領域へのアクセスを禁止されても閲覧全体をクラッシュさせず、設定変更後に再試行できる。 |
| PDF閲覧 | 取得失敗を個別に再試行。更新・資料変更・再認証時にページと倍率を保持し、添付PDFの位置とは分ける。 |
| 部分翻訳 | 単独表示も原文のページ対応を使用。訳文なし・ページ範囲外には案内を表示し、別のページへ丸めない。原文や別論文を訳文とする不正な対応を拒否する。 |
| PWA | 初期登録失敗を接続復帰時に再試行。オフライン起動時に既存Workerが有効なら失敗と誤表示しない。静的資産限定キャッシュと全タブ終了後の更新を維持する。 |
| PCのOCR済みPDF | ページ全体のスキャンを図版と誤認し、訳文を一切置けなくなる問題を修正。OCR済みページの背景画像だけを回り込み対象から外し、元のスキャンと図版保護を維持する。OCRを実行せず保存済みデータで再現する試験も追加した。 |

## 検証方法と限界

公開時のCI確認では、既存のPythonコードにも型エラーが見つかった。矩形座標の明示的な取り出し、合成クラスのメソッド宣言、Windows専用PATH処理のOS判定で修正し、Windows・Linux設定の両方でPyrightを確認する。型チェック対象の除外は増やさない。

Python全体試験の失敗も確認し、修正前の独立チェックアウトで4件の再現を取った。現在の図版名・要約の監査スキーマに合わないダミー応答、WindowsのパスをPOSIXのPathで解釈していた試験、Windows用CLIシムのOS模擬不足、見出しで始まることを仮定していたリリースノート試験を更新する。リリースノートは更新前後の本文一致、要約はページ引用と監査を通す形で検証する。既存の翻訳を自動的に無効化しない判断で現在の組み込みプロンプトの全文ハッシュを固定し直す。

TypeScript（アプリ・単体試験・ブラウザー試験）、ESLint、単体テスト、実際のEdgeを使うブラウザー試験、Webの本番ビルドを実施する。ブラウザー試験はGoogle・Driveを合成応答に置き換え、実際の個人資料を変更しない。PCとの取り込み試験では実際のPython処理も通す。

復旧試験はログインキャンセル・遅い認証応答・SDK取得失敗・PDF取得失敗・容量不足・未配置テキスト・別アカウント・欠落訳文・不正ページを含む。既存の筆跡、消去、取り消し、PCへの取り込み、リサイズ・回転・拡大、共通パネル、狭い画面、PWAのオフライン起動と複数タブ更新も確認する。公開後は同じブラウザー試験を公開URLへ向け、配信資産の一致を確認する。

iPad実機、Apple Pencilの実際の入力、SafariでのGoogle認証ポップアップはこの環境では検証できない。Edgeのタッチ・ペンイベント試験を実機確認と扱わない。端末の強制終了・OSの保存領域削除・完全に同時のタブ間編集を含む無損失保証は行わない。閉じる前に保存エラーを解消する。入力中の文字は端末内だけにあり、配置確定後にDriveへ送る。
