# PDFの書き込み

リーダー上部のツールバーで「目次」のすぐ左にある「書き込み」（ペンのアイコン）から書き込みツールバーを開いて操作します。通常表示・集中表示ともに同じ位置に文字付きで表示し、閉じている間も淡い青で入口を示します。ツールバーは原文・日本語訳で1本だけ表示し、最後にクリックした側のPDFに作用します。対象はツールバー左端の「原文／訳文」でも切り替えられます。読み込みが完了すると編集できます。

書き込みツールバーは、ペンなどの書き込みツールを選んでいる間と書き込み一覧を開いている間は表示したままになります。右端の×（またはリーダー上部の「書き込み」）で閉じると本文選択に戻り、読むときはPDFを広く表示します。起動したときは閉じた状態から始まります（設定「表示」の「書き込みバー」で、開いた状態で始めるか、前回の開閉の状態を引き継ぐかも選べます）。同期で他のPCのライブラリを取り込んだときやバックアップから復元したときも画面を読み込み直すため、同じく設定どおりの状態（既定では閉じた状態）に戻ります。ウィンドウが狭いときはツールのボタンがアイコンだけになります（ボタンにマウスを重ねると名前を表示します）。

ツールのモードは左右で同期します。片側でペン・蛍光ペン・図形などを選ぶと、反対側でもそのまま使えます。最後に使った描画の種類と選択方法も共有します。書き込み内容、選択範囲、元に戻す履歴、編集ロックは各側で個別に管理します。

| ツール | 操作 |
| --- | --- |
| 本文 | PDFの文字を選択・コピー。書き込みは表示したまま本文を読めます |
| 書き込み選択 | 四角／投げ縄で書き込みを囲み、移動・コピー・回転。青い枠と編集ハンドルを表示 |
| 範囲を切り取る | 四角で囲み、プレビューから画像コピー／メモに追加。「書き込みを含める」で描画・テキストも含められます |
| ペン・図形 | 種類をペン／蛍光ペン／直線／矢印／四角／丸から選択。色と太さ（細・中・太）を変更できます |
| 消しゴム | 線やテキストボックス全体を削除。「部分消しゴム」で触れた部分だけ削除。「蛍光ペンだけ消す」で対象を限定 |
| テキスト | ページをクリックして入力し「確定」。テキストツールで既存の文字をクリック、または書き込み選択ツールでダブルクリックすると再編集 |
| 付箋 | テキストの隣のボタンから貼り付け。クリックで選択し、本文・選択ツールでドラッグして移動。ダブルクリックまたはEnterで編集、Delete / Backspaceで削除 |

付箋には分類ラベルと本文の冒頭2行を表示します。本文が空の場合は引用を表示し、長い内容は省略します。ホバーすると全文を確認できます。

直線・矢印・四角・丸のツールではドラッグで新しい図形を描き、同じ種類の既存図形をクリックすると選択します。描いた直後もその図形が選択されますが、ツールは切り替わらず、別の場所から続けて描けます。選択した図形は白い端点をドラッグして変形、本体をドラッグして移動、枠から出た丸をドラッグして回転できます。丸の選択枠の角には、中心を保って全体を拡大縮小する四角いハンドルも出ます。選択中の図形の上から新しく描くときは Alt を押しながらドラッグします。空白をクリックするか Esc で選択を解除できます。Shift を押して描くと、線・矢印は45度刻み、四角・丸は正方形・真円になります。ドラッグ中の Esc は操作を取り消します。

ドラッグ中に Delete・Undo などの操作を実行すると、編集中のプレビューを取り消してから、確定済みの書き込みにその操作を適用します。矢印の矢じりは、短い矢印やページ端では収まる大きさになり、長くしたりページ端から離したりすると元の大きさに戻ります。

蛍光ペンは直線／フリーハンドを切り替え、Shiftを押すと水平線になります。投げ縄は線全体が囲まれた書き込みを選びます。範囲の切り取りは書き込みのロック・非表示中も利用できます。Escで本文選択に戻ります。

Apple Pencilなどのペン入力で直線・矢印・四角・丸を描く場合、一瞬ペンが離れても、0.3秒以内に直前のペン先から24画面ピクセル以内へ戻すと同じ図形のサイズ調整を続けられます。時間が経過した場合や離れた場所から描き始めた場合は確定します。手書きのペン・蛍光ペンは一筆ごとに分かれます。描画中の線は画面の更新に合わせて追従し、ページ移動やツール切り替え時にも描画内容を保存します。

消しゴムの大きさは「小・中・大」から選べます。円形カーソルが消す範囲を示し、選んだ大きさは再起動後も復元されます。

部分消しゴムはペン・蛍光ペンの線の触れた部分だけを削除します。オフの場合は線全体を削除します。図形とテキストは部分消しゴムでも全体を削除します。「蛍光ペンだけ消す」が有効なときは図形とテキストを残します。

## 選択した書き込みの編集

- 選択枠の内側をドラッグすると移動します。
- 角のハンドルをドラッグすると縦横比を保って拡大・縮小します。
- 直線・矢印・四角・丸を1つだけ選ぶと、角のハンドルの代わりに図形の端点（直線・矢印は両端、四角は4つの角、丸は縁の上下左右の4か所）にハンドルを表示します。端点をドラッグするとその形に変形し（矢印は矢じりの向きも変わります。傾けた四角は傾きを保ち、対角の角を固定します）、丸は上下左右のハンドルをドラッグするとその方向だけ縦または横に伸び縮みし（反対側は動きません。回転した丸も傾きに沿って伸縮します）、選択枠の角の四角をドラッグすると中心を保ったまま全体を拡大縮小します。丸のほかの縁は本体と同じく移動に使います。Shift を押しながら端点をドラッグすると、線・矢印は45度刻み、四角・丸は縦横比を保ちます。
- 枠から出た丸をドラッグすると回転します。ページ上端に近い図形では丸を枠の下側に表示します。0・90・180・270度の前後5度で自動的にスナップします。テキスト・図形はすでに傾いていてもページの水平・垂直に揃います。複数選択時はテキストを優先した基準の1件に合わせ、グループ全体を回転します。手書きだけの選択はドラッグ開始時からの回転角を基準にします。Shiftでは従来どおり15度刻みで回転します。書き込み選択の「…」にも拡縮・15度回転があります。
- 書き込み（選択中の枠の内側、または書き込みの上）を右クリックするか、指・Apple Pencil で長押し（約0.5秒、動かさない）すると「削除」メニューを表示します。書き込みの上で押したときは、その書き込みを選択して開きます。書き込み選択ツールで使えます。
- 書き込み選択の「…」→「色・太さを変更」で、選択した書き込みを変更します。
- コピー・切り取り・貼り付け・複製・削除を利用できます。アプリ内の別ページ、別の論文、原文と日本語訳の間でも貼り付けられます。
- 書き込み選択の「…」から全選択・複製・削除ができます。元のPDF本文は変更しません。
- 描画・移動・拡縮・回転・色変更・消去・貼り付けは、ページごとに最大50操作まで元に戻せます。履歴はアプリを開いている間保持します。

| キー | 操作 |
| --- | --- |
| Ctrl+C / X / V | コピー／切り取り／貼り付け |
| Ctrl+A | 書き込み選択ツールでページの書き込みを全選択 |
| Delete / Backspace | 選択を削除 |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| 矢印 / Shift+矢印 | 選択を少し移動／大きく移動 |
| Esc | 選択解除。選択がないときは本文ツールに戻る |
| Ctrl+Enter | テキスト入力を確定 |

ショートカットは最後に操作したPDF側の編集ツールで有効です。テキスト入力欄では通常の文字編集を優先します。

## 表示・整理・ペン設定

- 上段の「…」に非表示・編集ロック・書き込み一覧・PDF保存をまとめています。表示設定はPDF書き出しには影響しません。
- 書き込み一覧で、書き込みのあるページと件数を表示し、そのページへ移動できます。
- ペン／蛍光ペンの色と太さ、消しゴム設定は再起動後も復元されます。「お気に入り」から色・太さの組み合わせを最大8件まで保存できます。

## 範囲の切り取り

初期状態では元PDFを切り取ります。「書き込みを含める」にチェックすると、ペン・蛍光ペン・図形・テキストを含むプレビューに更新します。書き込みが非表示でも、チェックした場合は含めます。「画像をコピー」はPNGをクリップボードに入れ、画像の貼り付けに対応するアプリで利用できます。「メモに追加」は画像と出典ページへのリンクを読書メモに挿入します。画像はライブラリ内に保存され、バックアップにも含まれます。

手書きノートでも同じ書き込みツールを使えます。最初に開くとペンが選ばれ、選んだ用紙色のまま表示します。ノートのページ一覧には保存済みの書き込みと保持中の下書きを重ねます。ページの追加・並べ替え・削除や用紙変更の前に、表示していないページの下書きも保存します。保存できない場合はページを変更せず、下書きを保持します。詳しくは [手書きノート](notebooks.md)。

## 保存とPDF出力

書き込みはページごとに自動保存されます。ページ移動後も保存は継続します。失敗すると未保存の表示が出るので「再試行」を押してください。上段の「…」→「保存を再試行」でも、その側の保留中の書き込みをまとめて保存できます。

「書き込み付きPDFを保存」は選んだ側の全ページを別ファイルに出力します。ペン・蛍光ペン・図形はPDF描画、テキストはフォントを埋め込んだPDFテキストとして出力します。文章のハイライト（下記「付箋」）も、書き込みの下に半透明の四角形として描き込みます。外部PDFアプリで選択・編集できる標準注釈形式ではありません。アプリ内には編集可能な書き込みデータが残ります。

翻訳中の訳文PDFの書き出しは翻訳完了後に利用できます。訳文の再生成で配置が変わった場合、書き込みは同じページ位置に残ります。

## 付箋

付箋は、論文の気になる箇所に印・引用・自分のメモを残す機能です。読書を再開する位置とは別に、あとで探して読み返したい内容を保存します。

### 貼る

- 書き込みツールバーの「付箋」を押し、文章・図・数式のそばをクリックします。Escまたは「キャンセル」で位置選択を終了できます。
- 本文を選択すると、選択の上に小さなツールバーが出ます。「付箋」または右クリック →「選択した文章に付箋を貼る…」では、選択文も引用として取り込みます。
- 書き込み選択の「…」→「選択した書き込みに付箋を貼る」も利用できます。位置は保存時点のもので、その後の書き込みの移動には追従しません。
- テキスト書き込みと共通の小さな入力ダイアログで、分類とメモを入力して「確定」します。メモなしで印だけ残すこともできます。Ctrl+Enterでも確定できます。引用は「引用を確認」を展開して読めます。

### 文章のハイライト

本文を選択すると出る小さなツールバー（書き込みツールでペン・消しゴム・範囲選択などを使っている間と、付箋の位置選択中は出ません）で、ダイアログなしに文章へ色を付けられます。

- 色（黄・緑・青・ピンク・紫）を押すとすぐに保存します。右クリックの「ハイライト（色）」は最後に使った色で付けます。
- 「説明」はチャットにこの箇所の説明を頼み、「メモへ」はページへのリンク付きの引用をメモの末尾に加えます（どちらも右パネルで開きます）。「付箋」は付箋の入力ダイアログを開きます。
- PDF上のハイライトをクリックすると、色の変更・説明・メモへ・メモ（付箋）を書く・削除のツールバーが出ます。メモがあるハイライトは最後の行の右に小さな印を表示します。
- ハイライトは付箋の一種（種類「ハイライト」）として、選択した文章（引用）と、ページ上の位置（表示倍率によらないページ内の割合の四角形）を保存します。付箋タブに色付きのカードで並び、検索・「付箋・ハイライト」の絞り込み・削除と取り消し・メモへの書き出しは付箋と同じです。分類は付けなくてもかまいません。
- ダーク表示で「反転」にしているときも、ハイライトの色は反転しません。
- 訳文を作り直して文章の位置が変わった場合、ハイライトは保存したときの位置に残ります（書き込み・付箋と同じ）。

### 読む・編集する

- PDF上の付箋マーカーをクリックすると、小さな編集ダイアログが開きます。PDFの横に付箋パネルは表示しません。
- 上部の「付箋」タブ（Ctrl+5）で、保存した付箋をカードの一覧で見られます。カードには引用文と自分のメモを別々に表示します。
- カードをクリックするとPDF上と同じ編集ダイアログが開きます。編集するだけではタブや読書位置は変わりません。
- 「貼った場所へ」で「PDFを読む」タブに切り替え、対象論文の保存位置へ移動します。
- 「キャンセル」またはEscでダイアログを閉じます。未保存の変更がある場合は破棄する前に確認します。
- 集中表示中は読書ツールバーの付箋アイコン（幅が狭いときは「…」メニュー）、またはCtrl+5で集中表示を終了して付箋タブを開きます。

### 探す・整理する

- 付箋タブの「この論文／すべての論文」で対象を切り替え、引用文・メモ・論文名・分類を検索できます。Ctrl+Fで検索欄に移動します。論文を開いていない場合はすべての論文の付箋を表示します。
- 空白で区切った複数語は、すべての語を含む付箋を表示します。英字の大小・全角半角を揃えて検索します。
- 分類、原文／訳文で絞り込み、ページ順／追加が新しい順を選べます。「条件をクリア」で検索語と絞り込みを解除します。
- PDFへ移動しても検索条件と一覧のスクロール位置を保持します。
- 「この論文」を表示しているときは「メモに書き出す」で、表示中の付箋（「付箋とハイライト」または「付箋だけ」）をページ順に、p.N のリンク付きの Markdown リストとしてメモの末尾に追記し、メモタブを開きます。リンクを押すとそのページを開きます。絞り込み中は表示中のものだけを書き出します。
- カードのゴミ箱ボタン、またはカードを選んでDelete / Backspaceで削除します。PDF上の付箋もクリックで選んでDeleteで削除できます。削除後は付箋タブの「削除を取り消す」で戻せます。取り消し履歴はアプリを開いている間保持し、最後に削除した付箋から戻します。復元された付箋は新しく追加した付箋として扱います。

以前のしおりは、引用・メモ・分類・保存位置を引き継いで付箋として表示します。付箋とハイライトはライブラリのバックアップと Google Drive 同期に含まれます（同期の確認画面の「付箋」の件数にはハイライトも含みます）。PDFファイルへは、ハイライトだけを「書き込み付きPDFを保存」で描き込みます。付箋の書き出しには対応していません。
## 複数の読書メモ

「メモ」の「新規メモ」で論文ごとに複数の Markdown メモを作れます。名前変更・順序変更・削除、編集とプレビューの切替、検索・置換に対応します。リストの末尾で Enter を押すと次の項目を続けます。入力は自動保存され、失敗した内容は画面を切り替えても保持し、保存を再試行できます。

.md ファイルは「.md を取り込む」または論文行・メモ欄へのドロップで新しいメモとして取り込みます。UTF-8 の .md のみを扱い、PDF と混在したドロップは取り込みません。左パネルの論文の矢印を開くと先頭5件と「ほか n件」が現れ、選ぶと PDF の右にメモを開きます。最初は閉じています。

PDF の「メモへ」「メモに引用」、付箋の「メモに書き出す」、切り抜きの「メモに追加」、テンプレートは選択中のメモへ追記します。メモがまだない場合は1つ作って追記します。保存先は `papers/<論文ID>/attachments/<メモID>.md`、名前・順序・更新日時はデータベースの `attachments` に記録します。

従来の `note.md` / `papers.note` の内容はライブラリを開くと一度だけ変換し、以後は新形式のみを読み書きします。両方の内容が異なる場合は2つのメモとして保持します。書込みが失敗した場合は旧内容を消さずにエラーにし、再実行しても複製しません。複数メモ本文の横断検索・チャット参照にはまだ対応していません。
